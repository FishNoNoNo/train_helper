# Train Helper

一个更快速的 12306 桌面客户端，支持 GUI 和 CLI 两种使用方式。

本项目目标是把 12306 的常用购票流程压缩得更直接：搜索车票、选择候选班次、配置乘车人、提交预定，并在等待订单结果时给出清晰状态。

## 开源范围

本仓库公开以下内容：

- `src/`：完整前端源码（Vue 3 + TypeScript）
- `src-tauri/`：完整 Rust 后端源码（Tauri v2）
- `12306.postman_collection.json`：接口调试用 Postman Collection
- `api.md`：12306 API 接口文档

完整 App 也会以安装包形式提供。

## App 能做什么

- 免登录搜索车票
- 多选候选班次（购物车模式）
- 登录态检查 & 二维码登录
- 乘车人配置
- 座位等级、票种、座位偏好配置
- 自动批量提交预定（赛跑式抢票）
- 订单等待状态展示
- 系统托盘任务状态提示
- **🆕 CLI 命令行模式** — 在终端直接查询车票

## 使用流程

```text
搜索车票 -> 选择候选班次 -> 检查登录 -> 配置乘车人和座位 -> 开始预定 -> 查看结果
```

最终只会真正预定第一个提交订单成功的班次。

## CLI 命令行使用

Train Helper 支持在终端中直接查询车票，无需打开 GUI。

```bash
# 基本查询
train_helper query --from 北京 --to 上海 --date 2026-07-01

# 简写形式
train_helper query -f 北京 -t 上海 -d 2026-07-01

# 仅高铁/动车
train_helper query -f 北京 -t 上海 -d 2026-07-01 --gd

# 学生票
train_helper query -f 北京 -t 上海 -d 2026-07-01 --student

# JSON 格式输出（方便脚本处理）
train_helper query -f 北京 -t 上海 -d 2026-07-01 --json
```

### 输出示例

```
车次       出发 → 到达                日期          发时    历时    二等座  一等座  硬卧    软卧    无座  状态
G101      北京南 → 上海虹桥            2026-07-01    06:10  4h30m  有      有      --      --      --    预订
G103      北京南 → 上海虹桥            2026-07-01    06:20  4h35m  32张    无      --      --      --    预订
D321      北京 → 上海                  2026-07-01    08:05  12h    有      有      --      --      --    预订

共 3 趟车次
```

### 可用参数

| 参数 | 简写 | 说明 | 示例 |
|------|------|------|------|
| `--from` | `-f` | 出发站名称 | `北京`, `上海虹桥` |
| `--to` | `-t` | 到达站名称 | `上海`, `杭州东` |
| `--date` | `-d` | 出发日期 | `2026-07-01` |
| `--student` | — | 学生票查询 | — |
| `--gd` | — | 仅高铁/动车 | — |
| `--json` | — | JSON 格式输出 | — |

## 开发

### 环境要求

- Node.js 18+
- Rust 1.70+
- 系统 WebView2 (Windows 10+ 自带，或 macOS/Linux 对应组件)

### 构建与运行

```bash
# 安装前端依赖
npm install

# 启动开发模式（带热更新）
npm run tauri dev

# 仅启动前端（浏览器开发，不含 Tauri 功能）
npm run dev

# 生产构建
npm run tauri build
```
